# 🏡 [최현준 ♥ 조아영] 우리 집 공동생활 포털 & 구글 시트 연동 가계부

> **"서로 다른 두 사람이 만나 함께 살아가는 공간에서, 서로의 성향을 깊이 존중하고 신뢰를 쌓아가기 위한 스마트 공동생활 플랫폼"**  
> **커플 공동생활 합의서 제정일:** 2026년 11월 8일

## 📌 1. 프로젝트 개요 및 아키텍처

본 프로젝트는 **최현준 ♥ 조아영** 커플의 공동생활 합의서를 바탕으로 제작된 **모바일/데스크톱 완벽 대응 올인원 포털 웹 애플리케이션**입니다.

- **프론트엔드 (`index.html`):** 별도의 빌드 과정 없이 정적 웹 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 즉시 배포할 수 있는 단일 페이지 애플리케이션(SPA). Tailwind CSS, Pretendard 폰트, FontAwesome 아이콘 적용.
- **백엔드 & 데이터베이스 (`Code.gs`):** 구글 드라이브(5TB) 내의 Google Spreadsheets를 무료 클라우드 DB로 사용하고, Google Apps Script(Web App API)를 통해 두 사람의 스마트폰/PC에서 실시간으로 데이터를 양방향 동기화(GET / POST).
- **오프라인 폴백 (LocalStorage):** 구글 시트 연동 전이거나 오프라인 상태에서도 끊김 없이 모든 기능을 테스트하고 사용할 수 있도록 브라우저 로컬 저장소를 완벽 지원.

## 🚀 2. 탭별 핵심 기능 및 비즈니스 로직

- **접속 당일 기준 자동 계산 배너:**

  - **이번 주 일요일 쓰레기 & 기본 빨래 당번:**  
    매월 1·3주 차 일요일 `조아영` / 2·4주 차 일요일 `최현준` (다가오는 일요일 날짜 및 주차 자동 계산)
  - **이달의 로봇청소기 월 1회 정기 대청소:**  
    홀수월(1,3,5,7,9,11월) `최현준` / 짝수월(2,4,6,8,10,12월) `조아영`
- **주요 일정 & 3대 필수 기념일 고정 카드:**
  - 조아영 급여일(16일), 최현준 급여일(21일) D-Day 실시간 계산.
  - **공동 생활비 통장 자동이체일: 매월 25일 (이월 절대 금지!)**
  - **3대 필수 기념일:** 서로의 생일, 크리스마스(12/25), 결혼기념일 (배지 및 D-Day 표기).
- **주간/격주 가사 체크리스트 (클라우드 DB 실시간 동기화):**
  - 일요일 쓰레기/분리수거 배출, 기본 빨래 & 함께 개기, 진공청소기 격주 교대, 안방 화장실(현준 전담), 바깥 화장실(아영 전담), 로봇청소기 종합 세척.
  - 진행률 프로그레스 바 제공, 매주 리셋 및 신규 항목 동적 추가 지원.

### 2) [탭 2] 공동생활 합의서 전문 (인쇄/PDF 최적화 뷰)
- 제1장(성향 존중 및 소통 규칙), 제2장(가사 분담 및 공간 골든 룰 4대 원칙), 제3장(생활비 및 세부 지출 기준) 수록.
- **공간 수납 골든 룰 4원칙:** 외출복 즉시 정리, 소파 위 잠옷/트레이닝복 단 1벌 허용, 택배 현관 밖 개봉(외박스 문 밖, 속박스만 반입), 새 물건 사전 합의.
- **A4 인쇄 최적화 (`@media print`):** 상단 네비게이션 및 버튼이 자동 숨김 처리되며, 깔끔한 서명란이 포함된 서약서로 출력/PDF 저장 가능.

### 3) [탭 3] 공동생활비 & 월말 결산 가계부 (구글 시트 연동)
- **상단 요약 KPI 대시보드 (`총수입 - 총지출 = 잔여 자금`):**
  - 2인 총수입 (월급 + 투잡/부수입)
  - 공동 지출 + 공동 목돈 (생활비 + 조아영 관리 공동투자/여행자금)
  - 개인 지출 & 자산/투자 (현준 / 아영 분리 표시)
  - 최종 잔여 자금 및 저축/잉여율(%) 실시간 집계.
- **스페셜 기능 — 장거리 통행료(톨비) 정산 카운터:**
  - 장거리 이동 톨비 입력 시 "공동계좌에서 개인계좌로 이체해 줄 정산 총액" 별도 계산.
  - 정산 목록 등록과 동시에 **공동 생활비(차량 주차비·장거리 톨비) 지출 내역에도 자동 반영**.
- **세분화된 카테고리 & 빠른 금액 입력 (+1만, +5만, +10만, +50만, +100만):**
  - 주체별(공동/현준/아영) 맞춤 카테고리 필터링.
  - CSV 다운로드 및 검색 지원.

### 4) [탭 4] AI 객관적 월말 결산 프롬프트 생성기
- **목적:** 감시나 추궁이 아닌, AI 기반의 제3자적 객관적 피드백과 따뜻한 격려.
- 선택한 연월의 수입, 공동비, 개인비용, 톨비, 잉여자금 데이터를 마크다운 포맷으로 자동 변환.
- **[📋 프롬프트 클립보드 복사]** 버튼을 통해 ChatGPT, Claude, Gemini에 바로 붙여넣어 4대 분석(칭찬과 격려, 공동생활비 진단, 지출/투자 밸런스 피드백, 다음 달 3가지 실천 미션)을 즉시 제공받을 수 있음.

## 🛠️ 3. Google Apps Script (`Code.gs`) 백엔드 구축 Step-by-Step

구글 드라이브(5TB)에 새 스프레드시트를 하나 만들고 웹 앱 API로 배포하는 방법입니다.

### [Step 1] 구글 스프레드시트 생성
1. [Google 드라이브](https://drive.google.com/)에 접속합니다.
2. 좌측 상단 `+ 새로 만들기` > `Google 스프레드시트`를 생성합니다.
3. 시트 제목을 `[최현준♥조아영] 우리집 공동생활 DB`로 지정합니다.

### [Step 2] Apps Script 편집기 열기 및 코드 붙여넣기
1. 스프레드시트 상단 메뉴에서 **`확장 프로그램`** > **`Apps Script`**를 클릭합니다.
2. 기본으로 적혀있는 `function myFunction() {}` 코드를 모두 지웁니다.
3. 프로젝트 내의 **`Code.gs`** 파일 내용을 전체 복사하여 붙여넣고 저장(`Ctrl + S`)합니다.

### [Step 3] `setupSheets()` 함수 1회 실행 (시트 자동 생성)
1. 상단 툴바의 함수 선택 드롭다운에서 **`setupSheets`**를 선택하고 **`실행`** 버튼을 클릭합니다.
2. **권한 검토 팝업이 뜨는 경우:**
   - `권한 검토` 클릭 > 본인 구글 계정 선택
   - `Google에서 확인하지 않은 앱입니다` 경고 창에서 좌측 하단 **[고급]** 클릭
   - **`[프로젝트명](으)로 이동(안전하지 않음)`** 클릭 > **[허용]** 클릭
3. 실행 완료 후 스프레드시트로 돌아가면 아래 3개의 시트 탭이 자동 생성되어 있습니다:
   - `Transactions` (거래 내역)
   - `Tolls` (장거리 톨비 정산)
   - `Checklist` (가사 체크리스트)

### [Step 4] 웹 앱으로 배포 (가장 중요 ⭐)
1. Apps Script 편집기 우측 상단 파란색 **`배포`** 버튼 > **`새 배포`** 클릭.
2. 좌측 톱니바퀴 아이콘(유형 선택) 클릭 > **`웹 앱`** 선택.
3. 배포 설정 입력:
   - **설명:** `우리집 포털 v1.0`
   - **다음 사용자 권한으로 실행:** `나(내 이메일)`
   - **액세스 권한이 있는 사용자:** <span style="color:red; font-weight:bold;">모든 사용자 (Anyone)</span>
     > ⚠️ 반드시 **"모든 사용자"**로 설정해야 최현준, 조아영 두 사람이 로그인 인증 오류 없이 스마트폰에서 자유롭게 데이터를 읽고 쓸 수 있습니다.
4. **`배포`** 버튼을 누르고, 생성된 **`웹 앱 URL`**(예: `https://script.google.com/macros/s/.../exec`)을 복사합니다.

### [Step 5] 우리 집 포털 웹페이지에 URL 등록
1. 배포된 `index.html` 웹페이지를 브라우저로 엽니다.
2. 상단 우측의 **`설정(⚙️)`** 버튼 또는 **`[로컬 모드]`** 배지를 클릭합니다.
3. 복사한 Apps Script 웹 앱 URL을 붙여넣고 **`연결 테스트`**를 누른 뒤 **`설정 저장하기`**를 클릭합니다.
4. 상단 배지가 **`구글 시트 연동됨 🟢`**으로 변경되면 실시간 연동이 정상 완료된 것입니다!

## 🌐 4. 프론트엔드 무료 웹 호스팅 배포 방법

`index.html` 단일 파일로 구성되어 있으므로 아래 중 원하는 곳에 1분 만에 무료 배포할 수 있습니다.

### 방법 A: GitHub Pages (추천)
1. GitHub에 새 저장소(예: `our-home-portal`)를 생성합니다 (Public 또는 Private).
2. `index.html`, `Code.gs`, `README.md`를 업로드(Push)합니다.
3. 저장소의 `Settings` > `Pages` 이동.
4. `Branch`를 `main` (또는 `master`), 폴더를 `/(root)`로 지정 후 `Save`.
5. 1~2분 후 생성되는 `https://[깃허브ID].github.io/our-home-portal/` 주소로 두 사람 모두 접속할 수 있습니다.

### 방법 B: Cloudflare Pages / Netlify (초간편 드래그 앤 드롭)
1. [Netlify Drop](https://app.netlify.com/drop)에 접속합니다.
2. `index.html`이 들어있는 폴더를 브라우저 창에 드래그 앤 드롭합니다.
3. 즉시 무료 도메인(예: `https://our-happy-home.netlify.app`)이 발급됩니다.

## 📱 5. 스마트폰 홈 화면에 추가 (PWA 앱처럼 사용하기)

두 사람의 스마트폰 홈 화면에 아이콘을 추가하면 일반 네이티브 앱처럼 1초 만에 실행할 수 있습니다.

### 아이폰 (iOS Safari)
1. Safari 브라우저에서 배포된 포털 웹사이트 주소로 접속합니다.
2. 하단 중앙의 **공유 아이콘(네모 위로 화살표)**을 탭합니다.
3. 메뉴를 아래로 내려 **`홈 화면에 추가`**를 선택합니다.
4. 이름(예: `우리집 포털`)을 확인하고 `추가`를 누릅니다.

### 갤럭시 / 안드로이드 (Chrome)
1. Chrome 브라우저에서 포털 웹사이트 주소로 접속합니다.
2. 우측 상단 **메뉴 버튼(점 3개 ⋮)**을 탭합니다.
3. **`홈 화면에 추가`** 또는 **`앱 설치`**를 누릅니다.
